## 2. ความปลอดภัยและ LOTO

### 2.1 ข้อควรระวังทั่วไป

- ห้ามเปิดฝาครอบป้องกัน (Guard Cover) ขณะเครื่องกำลังหมุน Spindle หรือ Dresser
- ห้ามสัมผัสหัวจับงาน (Work Head) และแกน Spindle ขณะเครื่องทำงาน มีความเสี่ยงจากใบเจียรหมุนความเร็วสูงและเศษน้ำมัน Coolant ร้อน
- น้ำมัน Coolant ที่ใช้ในกระบวนการเจียรมีฤทธิ์ระคายเคืองผิวหนัง ต้องสวมถุงมือกันสารเคมีและแว่นตานิรภัยทุกครั้งที่ปฏิบัติงานใกล้ระบบ Coolant
- เสียงจากการเจียรและมอเตอร์ Spindle เกินมาตรฐาน ต้องใส่ที่อุดหูตลอดเวลาที่อยู่ในพื้นที่เครื่องจักร

### 2.2 ขั้นตอน LOTO (Lockout–Tagout) ก่อนซ่อมบำรุง

1. แจ้งหัวหน้าไลน์ผลิตและ MT Leader ให้ทราบว่าจะหยุดเครื่องเพื่อซ่อมบำรุง
2. กด E-Stop และปิดโปรแกรม CNC ให้เครื่องหยุดสนิท (Spindle, Dresser, Transfer หยุดครบทุกแกน)
3. ปิดเบรกเกอร์ไฟหลัก (Main Breaker) ที่ตู้คอนโทรลประจำเครื่อง ล็อกด้วยกุญแจ Lockout ส่วนตัว และแขวนป้าย Tagout ระบุชื่อผู้ปฏิบัติงานและเวลา
4. ปิดวาล์วลมอัด (Main Air Pressure) และ Bleed ลมค้างในระบบให้หมดก่อนถอดชิ้นส่วนนิวเมติกส์
5. ปิดวาล์วจ่าย Coolant และรอให้ปั๊ม Coolant หยุดหมุนสนิทก่อนเปิดฝาถังหรือถอดท่อ
6. ทดสอบว่าไฟฟ้าและพลังงานถูกตัดจริงโดยกดปุ่ม Start ที่หน้าตู้ควบคุม (ต้องไม่มีการทำงานใด ๆ เกิดขึ้น) ก่อนเริ่มลงมือซ่อม
7. เมื่อซ่อมเสร็จ ให้ผู้ปฏิบัติงานตรวจสอบว่าไม่มีเครื่องมือ/ชิ้นส่วนตกค้างในเครื่อง แล้วจึงถอดล็อกและแจ้งฝ่ายผลิตก่อนสั่งเดินเครื่องทดสอบ

### 2.3 อุปกรณ์ป้องกันส่วนบุคคล (PPE) ที่ต้องใช้

| งาน | PPE ที่ต้องสวมใส่ |
|---|---|
| เดินเครื่องประจำวัน | แว่นตานิรภัย, ที่อุดหู, รองเท้านิรภัย |
| ตรวจเช็ค/เปลี่ยนลูกปืน Spindle | ถุงมือกันบาด, แว่นตานิรภัย, ที่อุดหู |
| งานเกี่ยวกับระบบ Coolant | ถุงมือกันสารเคมี, แว่นตานิรภัย, ผ้ากันเปื้อน |
| งานไฟฟ้าในตู้คอนโทรล | ถุงมือกันไฟฟ้าแรงต่ำ, รองเท้าฉนวน |

## 3. การใช้งานประจำวัน

### 3.1 การตรวจเช็คก่อนเริ่มงาน (Pre-operation Check)

1. ตรวจสอบระดับน้ำมัน Coolant ในถังว่าอยู่ในระดับที่กำหนด (ไม่ต่ำกว่าขีดต่ำสุด)
2. ตรวจสอบแรงดันลมอัด (Main Air Pressure) ที่เกจหน้าตู้ ต้องไม่ต่ำกว่า 4.5 bar
3. ฟังเสียงมอเตอร์ Spindle และ Dresser ขณะ Warm-up ว่ามีเสียงผิดปกติหรือไม่
4. ตรวจสอบฝาครอบป้องกัน (Guard Cover) ว่าปิดสนิทและสกรูยึดแน่นครบทุกจุด
5. เช็คหน้าจอ HMI ว่าไม่มี Alarm ค้าง หากมี Alarm ค้างห้ามเดินเครื่องจนกว่าจะแก้ไข

### 3.2 ขั้นตอนเดินเครื่องผลิต

1. โหลดโปรแกรม CNC ตาม Part Number ที่จะผลิตให้ตรงกับ Job Order
2. ทำการ Warm-up Spindle ตามรอบมาตรฐานอย่างน้อย 5–10 นาทีก่อนเริ่มผลิตจริง โดยเฉพาะหลังหยุดเครื่องข้ามคืน
3. ป้อนชิ้นงาน Inner Ring ผ่านระบบ Transfer เข้าสู่ Work Head
4. ตรวจสอบค่าขนาดชิ้นงานแรก (First Piece) ด้วยเครื่องมือวัดตามแผน Quality Check ก่อนปล่อยผลิตต่อเนื่อง
5. ระหว่างผลิต ให้ Operator สังเกตค่า Spindle Temperature และเสียงผิดปกติทุกชั่วโมง หากพบค่าอุณหภูมิสูงผิดปกติหรือมีเสียงสั่นให้หยุดเครื่องและแจ้งซ่อมทันที
6. เมื่อสิ้นสุดกะการทำงาน ให้บันทึกชั่วโมงทำงานและสภาพเครื่องจักรลงในสมุด Log ประจำเครื่อง

### 3.3 การหยุดเครื่องปกติ (End of Shift)

1. หยุดป้อนชิ้นงานและรอให้ชิ้นงานในไลน์ผ่านออกจนหมด
2. หยุด Spindle และ Dresser ตามลำดับผ่านโปรแกรม HMI
3. ปิดวาล์ว Coolant และปิดเครื่องตามขั้นตอนมาตรฐาน
4. ทำความสะอาดเศษเจียร (Swarf) บริเวณ Work Head และรางลำเลียง

## 7. การแก้ไขปัญหา (Troubleshooting)

| อาการ (Symptom) | สาเหตุที่เป็นไปได้ (Cause) | วิธีแก้ไข (Action) |
|---|---|---|
| ALM-1042 SPINDLE VIBRATION OVER LIMIT | ตลับลูกปืน Spindle เสื่อมสภาพ/สึกหรอจากรอบการทำงานสะสม | หยุดเครื่องทันที ทำ LOTO แล้ววัดค่าความสั่นสะเทือนซ้ำ หากเกินพิกัดให้เปลี่ยนตลับลูกปืน Spindle (MTMC-0044) ห้ามฝืนเดินเครื่องต่อ |

## 9. ขั้นตอนการแจ้งซ่อมผ่าน QR / Work Order

1. เมื่อพบความผิดปกติที่หน้าเครื่อง GR-1141 ให้สแกน QR Code ที่ติดอยู่บริเวณตู้คอนโทรลของเครื่องจักรด้วยมือถือ/แท็บเล็ตของแผนก
2. ระบบจะเปิดหน้าโปรไฟล์เครื่องจักร GR-1141 ขึ้นมาอัตโนมัติ โดยแสดงข้อมูลเครื่องจักร, Alarm ที่ Active อยู่ (เช่น ALM-1042) และประวัติการซ่อมย้อนหลัง
3. กดปุ่ม "แจ้งซ่อม / สร้าง Work Order" แล้วกรอกรายละเอียด:
   - อาการที่พบ (Symptom) ให้ระบุให้ชัดเจนที่สุด เช่น ตำแหน่งที่เกิดอาการ (Work Head, Spindle, Dresser, Transfer)
   - ระดับความเร่งด่วน (Priority): low / medium / high ตามผลกระทบต่อสายการผลิต B
   - ผู้แจ้ง (Requested by) และกะการทำงาน (Shift)
4. ระบบจะออกเลข Work Order (เช่น รูปแบบ WOxxxxx) และแจ้งเตือนไปยัง MT Leader และช่างเทคนิคที่เกี่ยวข้องโดยอัตโนมัติ
5. ช่างเทคนิคที่ได้รับมอบหมายทำการ LOTO และดำเนินการซ่อมตามขั้นตอนในคู่มือนี้ พร้อมบันทึกสาเหตุ (Cause) และวิธีแก้ไข (Repair Action) ลงใน Work Order ทุกครั้งเพื่อสะสมเป็นประวัติสำหรับวิเคราะห์แนวโน้มในอนาคต
6. เมื่อซ่อมเสร็จให้ทดสอบเดินเครื่องตามขั้นตอนใน "3.2 ขั้นตอนเดินเครื่องผลิต" และปิด Work Order พร้อมระบุจำนวนขั้นตอนที่ทำสำเร็จ (Steps Completed / Total Steps)
7. หากอาการเกี่ยวข้องกับ Alarm ที่ Active ค้างในระบบ (เช่น ALM-1042) ให้ตรวจสอบว่า Alarm ถูกเคลียร์จริงที่หน้าจอ HMI ก่อนส่งคืนเครื่องจักรให้ฝ่ายผลิต
8. กรณีอะไหล่ไม่พร้อม (เช่น รอเปลี่ยนลูกปืน Spindle ตามกรณี WO95009) ให้บันทึกสถานะ Work Order เป็น "รออะไหล่" พร้อมระบุรหัสอะไหล่ที่ต้องใช้ (เช่น MTMC-0044) เพื่อให้ฝ่ายจัดซื้อ/คลังอะไหล่ติดตามการเบิกจ่ายต่อได้
